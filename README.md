# TG RAG Bot — Telegram RAG-бот для корпоративных документов

**Ваш Telegram-бот, который читает документы и отвечает на вопросы.**
Загрузите PDF, Excel, DOCX — и задавайте вопросы на естественном языке.

## ✨ Что умеет

- 📄 **Загрузка документов** — PDF, Excel (XLSX/XLS), DOCX, TXT, MD
- 🔍 **Семантический поиск** — находит ответ в документах с цитированием источника
- 🌍 **Мультиязычность** — отвечает на языке вопроса (EN, RU, ES, CN)
- 👥 **Управление пользователями** — история, язык, права доступа
- 📊 **Админ-панель** — аналитика, логи, управление
- 🔐 **API** — FastAPI бэкенд для интеграций

## 🧠 Технологии

| Компонент | Технология |
|-----------|-----------|
| **Бот** | Aiogram 3.0 (Python) |
| **Бэкенд** | FastAPI + SQLAlchemy |
| **RAG** | LlamaIndex 0.14+ |
| **AI** | OpenAI / Mistral совместимые |
| **Векторная БД** | ChromaDB (встроенная) |
| **БД** | SQLite / PostgreSQL |

## ⚡ Быстрый запуск

```bash
# 1. Клонировать
git clone <repo-url>
cd telegram-ai-bot

# 2. Установить
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt

# 3. Настроить .env
cat > .env << EOF
TELEGRAM_BOT_TOKEN=your_bot_token
OPENAI_API_KEY=your_openai_key
DATABASE_URL=sqlite:///bot.db
EOF

# 4. Запустить
python backend/app/main.py
```

Бот запущен и готов отвечать на вопросы по вашим документам.
