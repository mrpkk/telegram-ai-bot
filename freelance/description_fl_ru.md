# Описание для FL.ru

## Название услуги
```
Разработка AI-бота для бизнеса с админ-панелью и аналитикой
```

## Описание услуги

```
Разработаю Telegram-бота с искусственным интеллектом, который отвечает на вопросы ваших клиентов 24/7 на основе ваших документов.

Что умеет бот:
• Обучается на ваших документах (PDF, Word, TXT, Excel)
• Отвечает на вопросы клиентов в Telegram
• Указывает источник ответа (название файла + цитата)
• Работает 24/7 без оператора
• Собирает статистику по вопросам

Что входит в работу:
• Разработка Telegram-бота с AI (Mistral AI — бесплатно)
• RAG-система для поиска по документам
• Админ-панель для управления (загрузка документов, FAQ, аналитика)
• Настройка приветствия и тона ответов
• Docker-деплой на ваш сервер
• Инструкция по добавлению новых документов

Технологии: Python, FastAPI, LangChain, Mistral AI, ChromaDB, Docker, Streamlit.

Подходит для:
• Интернет-магазины (вопросы про товары, доставку, возвраты)
• Онлайн-школы (консультации, расписание, материалы)
• B2B-услуги (обработка заявок, презентации)
• Служба поддержки (типовые вопросы)

Преимущества:
• Все модели работают через API (бесплатно)
• Не требует GPU или мощного сервера
• Готов к использованию через 1-2 дня
• Исходный код полностью ваш
```

## От заказчика

```
Для начала работы понадобится:
• Документы в формате PDF (политики, инструкции, каталоги)
• Токен Telegram-бота (получить бесплатно у @BotFather за 2 минуты)
• Доступ к серверу для деплоя (или я помогу настроить на вашем компьютере)
```

## Результат для заказчика

```
Telegram-бот 24/7 + админ-панель + исходный код + инструкция
```
